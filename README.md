# Репозиторий НИР: Графовый анализ речи

**Тема исследования:** Прототип системы автоматического графового анализа речевой связности для мониторинга динамики когнитивных нарушений у пожилых людей.

**Дата начала работы:** 24 сентября 2026 г. 

## Назначение структуры папок:
* **00_Inbox** — Входящая информация, сырые идеи и быстрые заметки.
* **01_Literature** — Конспекты прочитанных научных статей и книг по лингвистике и медицине.
* **02_Notes** — Основная база знаний (Zettelkasten), атомарные заметки с тегами и вики-ссылками.
* **03_Projects** — Управление проектом разработки прототипа системы.
* **04_Drafts** — Черновики глав магистерской диссертации и статей.
* **05_Output** — Готовые отчеты, презентации и тексты на выходе.
* **_Templates** — Шаблоны для стандартизации новых заметок (например, шаблон для статей).
* **_Attachments** — Файлы, изображения, схемы и PDF-документы.
